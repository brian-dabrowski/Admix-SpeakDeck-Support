# Admix SpeakDeck

Admix SpeakDeck is a Windows plugin for Elgato Stream Deck that turns one key
into two local speech tools:

- Tap to read selected text aloud through an installed Windows SAPI voice.
- Double-tap to stop active speech or dictation.
- Hold, wait for the ready chime, speak, and release for local English
  dictation into the focused app.

The plugin processes dictation locally with a bundled Whisper model. It does
not require an account or send microphone audio or transcripts to Admix.
